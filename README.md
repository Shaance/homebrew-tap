# Shaance/homebrew-tap

```sh
brew install shaance/tap/hn
brew install shaance/tap/herder
```

`hn` reads Hacker News stories and comment threads in your terminal. Source and releases: https://github.com/Shaance/hn

`herder` dispatches, tracks and verifies coding agent runs (Codex, Vibe and Claude). macOS, Apple Silicon and Intel. Source and releases: https://github.com/Shaance/herder
